# Rehearsal Runbook

Use this runbook before a customer session or internal handoff.

## Run Order

1. Reset test data, queues, pending tasks, and demo inbox state.
2. Start happy path from the advertised entry point.
3. Pause at human review and confirm the Action App story is clear.
4. Complete the review with the intended decision.
5. Confirm downstream automation and final status.
6. Run one exception path.
7. Capture run identifiers, screenshots, and fallback evidence.

## Presenter Notes

Capture:

- What to say before triggering the demo.
- Where to pause.
- Which UI elements prove the value.
- What is automated, assisted, reviewed, mocked, or future integration.
- What to do if a connector, task, app, or job fails.

## Reset Notes

Record:

- Test case ids.
- Queue items or Data Fabric records to clear.
- Pending Action Center tasks to complete or cancel.
- Files or storage objects to remove.
- Package or process version currently in use.
