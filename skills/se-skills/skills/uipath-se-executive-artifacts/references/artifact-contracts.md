# Artifact Contracts

Use these output shapes for customer-facing SE artifacts.

## Executive Brief

- Customer context.
- Business challenge.
- Current-state pain.
- UiPath perspective.
- Future-state solution.
- Demo proof.
- Assumptions and open questions.
- Recommended next steps.

## One-Pager

- Headline value proposition.
- Current-state challenge.
- Future-state capability map.
- Demo scenario summary.
- Modeled impact with assumptions.
- What was demonstrated.
- Next steps.

## Demo Script

- Setup.
- Scene list.
- Presenter beats.
- Expected screen or artifact.
- What to say.
- What to avoid saying.
- Fallback if the live path fails.

## Architecture Diagram Narrative

- Intake.
- Orchestration.
- IXP or document understanding.
- AI Agent reasoning.
- RPA or connector system work.
- Human review.
- Data layer.
- Monitoring, audit, and deployment.
