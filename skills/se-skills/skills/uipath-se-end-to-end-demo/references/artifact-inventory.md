# Artifact Inventory

Use this checklist before claiming an end-to-end demo is designed or ready to build.

For build-oriented requests, this checklist is supporting evidence only. It does not satisfy the request unless executable, buildable, package-ready, or deployable non-Markdown artifacts also exist.

## Discovery And Design

- Source artifacts: transcripts, notes, diagrams, screenshots, PDFs, sample documents, call summaries, and repo evidence.
- Current-state process summary with actors, systems, handoffs, decisions, exceptions, and pain points.
- Future-state process summary with UiPath capability responsibilities.
- Fact versus assumption labels for volume, SLA, staffing, backlog, rework, savings, quality, risk, or conversion.
- Scenario matrix with at least two runnable branches and any visible mock branches.
- Presenter storyline with scenes, viewer takeaway, and expected proof.

## UiPath Artifacts

- Solution file and deployment notes.
- Orchestration project: Maestro Flow, Case Management, or BPMN.
- AI Agent project or inline agent configuration.
- RPA project or coded workflow.
- Action App or human-review task definition.
- IXP or document understanding project, mock extraction contract, or document fixture pack.
- Data Fabric entities, queues, assets, storage buckets, or fixture-backed contracts.
- Connector bindings and outbound communication templates.

## Contracts

- Intake payload.
- IXP or extraction payload.
- AI Agent input and output schema.
- RPA input and output schema.
- Action App task data and completion data.
- Document preview contract.
- Outbound communication contract.
- Case or process status model.
- Activity log model.

## Test And Handoff

- Synthetic documents or safe sample documents.
- Fixture JSON for every branch.
- Expected final status per scenario.
- Demo inbox or communication recipient list.
- Manual trigger payloads for every entry point and event-trigger substitute.
- What is real, mocked, replaceable, and not yet implemented.
- Folder, process, package, app, task, and run identifiers needed for handoff.
