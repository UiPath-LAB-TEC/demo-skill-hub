  ## uipath-langchain agent

This project is a demo-grade UiPath Coded Agent that uses the uipath-langchain Python library. 
The agent is a document validator agent with structured inputs and outputs.
The agent uses a UiPath Context Grounding index `KYC_DocVal_AgentCG` for knowledge and a web search MCP server for search.

 ## Evaluations

This demo project will contain a dataset of 5 varied input examples for evaluations.
LLM as a judge trajectory evaluator will be used with appropriate criterion for judging the output and overall agent trace.
